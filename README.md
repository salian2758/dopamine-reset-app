# 🎯 Dopamine Reset App

App de hábitos gamificada para Rafa. Reset de dopamina, intervenciones sin fricción, testigo del futuro.

## 🚀 Deploy rápido a Vercel

### Opción 1: CLI Vercel (recomendado)

```bash
# 1. Instala Vercel CLI (si no lo tienes)
npm install -g vercel

# 2. Deploy
vercel

# 3. Sigue los pasos (conecta tu GitHub, elige repo, etc)
```

### Opción 2: GitHub + Vercel UI

```bash
# 1. Commitea todo a GitHub
git add .
git commit -m "Initial commit: Dopamine Reset App"
git branch -M main
git remote add origin https://github.com/salian2758/dopamine-reset-app.git
git push -u origin main

# 2. Ve a vercel.com
# 3. Conecta tu GitHub
# 4. Elige este repo
# 5. Deploy automático
```

## 🏃 Desarrollo local

```bash
npm run dev
```

Abre http://localhost:5173

## 📦 Build

```bash
npm run build
```

## Características

- 📅 Dashboard con capítulos, salud mental, tareas diarias
- 🆘 SOS con timer de resistencia
- 📋 Check-in diario con 6 hábitos
- 👶 Cartas del testigo (futuro hijo)
- 🎯 Intervenciones con filtros (fase + compañía + ubicación)
- 💾 localStorage offline

## Hábitos

- Pornografía
- Procrastinación
- Pantallas / Scroll
- Porros
- Tabaco / Nicotina
- Onicofagia (uñas)

## Stack

- React 19
- Vite
- CSS custom properties
- localStorage
